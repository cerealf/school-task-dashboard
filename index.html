🔑 One-time setup

A GitHub token is stored in your browser to fetch and close tasks. It never leaves your device.

  2. Click Generate new token
  3. Set repository access to Only select repositories → cerealf/school-digest-logs
  4. Under Permissions → Repository, set Issues → Read and write
  5. Generate and paste the token below
